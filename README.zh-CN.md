# rat 🐀

[English](README.md)

**A little Rusty rat chasing a C cat.**

一只 Rust 写的小老鼠，偏要追着 C 写的猫跑。

`rat` 是一个用 Rust 写成的小型命令行工具，用来浏览文件和目录。

它最初只是一次重写 `cat` 的小练习，后来长成了一个稍有不同的工具：它会自动识别给定路径指向的是文件还是目录，并以合适的方式展示出来。

一个 Rust 源文件。零外部依赖。就是一只小老鼠，忙着做自己的事。

## 为什么叫 rat？

这个名字里藏着一点文字游戏：

- 传统的 **cat** 通常用 **C** 编写。
- **rat** 用 **Rust** 编写。
- 猫会追老鼠；而这只老鼠在追 `cat`。

只换一个字母，就换了一门语言，也轮到老鼠登场了。

`rat` 从 `cat`、`stat` 和 `tree` 借来了一些想法，但并不打算替代其中任何一个。它是一个围绕简单想法展开的 Rust 学习项目：

**给它一个路径，让老鼠自己判断该怎么做。**

## 认识 Rusty 🐀

![终端吉祥物 Rusty，身旁是一块乳酪](assets/rat-mascot.png)

不带路径直接运行 `rat`，Rusty 就会带着它的乳酪现身：

```bash
cargo run
```

Rusty 是 `rat` 的终端吉祥物：一只用 Rust 写出来的小老鼠。这个名字既呼应 Rust 语言，也带着英语 *rusty*（有点生锈、略显旧旧的）的俏皮意味；不过它依然兴致勃勃地追着那只 C 写的猫跑。

无参数模式会显示彩色吉祥物、当前终端标语与 `Usage: rat <path>`，随后正常退出。乳酪后面没有藏着交互菜单。

## 功能

### 查看文件

- 显示路径、类型和大小。
- 按原始字节输出文件内容。
- 保留原始空白、编码以及末尾换行（或没有末尾换行这一事实）。
- 报告文件访问和 I/O 错误。

### 浏览目录

- 自动识别目录。
- 递归遍历子目录。
- 按文件名的字母顺序排序条目。
- 用缩进展示目录层级。
- 支持在源代码中配置最大递归深度。
- 使用嵌入式忽略规则跳过不想看的文件和目录。

### 内部实现

- 使用 Rust 编写（Edition 2024）。
- 零外部依赖。
- 只有一个 Rust 源文件。
- 使用 Rust 标准库的文件系统和 I/O API。
- 通过 `Result`、`?` 与退出码处理错误。

## 开始使用

### 环境要求

需要 Rust 和 Cargo。

克隆仓库并构建：

```bash
git clone https://github.com/NingAloha/rat
cd rat
cargo build --release
```

可执行文件位于：

```text
target/release/rat
```

也可以直接通过 Cargo 运行：

```bash
cargo run -- <path>
```

## 用法

### 查看文件

```bash
cargo run -- Cargo.toml
```

示例输出：

```text
Path: Cargo.toml
Type: Regular file
Size: 83 bytes
------------------------
[package]
name = "rat"
version = "0.1.0"
edition = "2024"

[dependencies]
```

文件内容会直接复制到标准输出，不会添加、删除或修改任何字节。

### 浏览目录

```bash
cargo run -- src
```

示例输出：

```text
Path: src
Type: Directory
Size: 96 bytes
------------------------
main.rs
```

对于包含子目录的目录，`rat` 会用缩进展示其结构。

```text
project
    docs
        guide.md
    src
        main.rs
        utils.rs
    Cargo.toml
```

### ⚠️ 递归深度

**当前目录遍历默认不限制深度（`max_depth = -1`）。**

大型目录可能会产生海量终端输出。

若要改变此行为，请编辑 `src/main.rs` 中的 `print_directory_tree()` 调用：

```rust
print_directory_tree(path, 0, -1)?;
```

修改最后一个参数即可限制递归：

| 值 | 行为 |
|---|---|
| `-1` | 不限制递归（默认） |
| `0` | 仅显示直接子项 |
| `1` | 显示直接子项和再下一层 |
| `2` | 显示直接子项和再下两层 |

例如：

```rust
print_directory_tree(path, 0, 2)?;
```

修改后需要重新构建。

**提示：** 如果这只老鼠跑得太欢，把终端刷屏了，按 `Ctrl + C` 就能让它停下来。

## 老鼠不喜欢什么

老鼠也会挑三拣四。

`rat` 有一份自己的忽略清单，保存在项目根目录的 `.ratdontlike` 中。

当前清单为：

```text
.git
.idea
target
.DS_Store
```

浏览目录时，`rat` 会自动跳过名称与这些规则完全相同的条目；若条目是目录，也会跳过其中的内容。

### 工作方式

这份清单会在编译时直接嵌入可执行文件：

```rust
const DISLIKES: &str = include_str!("../.ratdontlike");
```

这意味着：

- 无需运行时配置文件。
- 无论当前工作目录在哪里，忽略规则都有效。
- 规则会在每一层目录中针对条目名称进行匹配。
- 空行和以 `#` 开头的行会被忽略。
- 匹配的是精确名称，不是通配符模式，也不是完整的 `.gitignore` 语法。
- 修改 `.ratdontlike` 后需要重新构建可执行文件。

例如：

```bash
rat .
```

遍历目录时会跳过 `.git`、`.idea`、`target` 和 `.DS_Store` 条目。

不过，用户明确指定的路径仍然可以访问：

```bash
rat .git
```

这只老鼠会尊重直接指令；只是浏览时会绕开自己不喜欢的东西。

**注意：** 构建时需要 `.ratdontlike` 源文件；运行已经编译好的可执行文件时则不需要它。

## 错误处理

如果路径不存在：

```bash
cargo run -- nonexistent.txt
```

示例输出：

```text
rat: nonexistent.txt: No such file or directory (os error 2)
```

发生操作错误时，`rat` 会将错误报告到标准错误，并返回非零退出码。

当前命令恰好只接受一个路径参数。

## 理念

**保持小巧。保持可读。保持 Rusty。**

`rat` 是个人学习项目，并不是要打造下一个伟大的 Unix 工具。

它遵循的原则很简单：

- **尊重字节。** 绝不改动文件内容，哪怕一个字节。
- **让路径自己说话。** 根据文件和目录各自的类型来处理它们。
- **保持轻量。** 优先使用 Rust 标准库，避免不必要的依赖。
- **保留个人色彩。** 工具应适合它的作者自己的工作流。
- **边做边学。** 理解代码比堆砌功能更重要。
